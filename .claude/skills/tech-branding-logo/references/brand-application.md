# Brand application

Start with existing guidelines/assets, desired asset and audience action. Determine which rules are approved, which inputs are missing, required dimensions/formats and exact copy/product requirements. Ask only about gaps that change the requested work.

Translate the established identity into the requested layout, packaging, post or presentation. Reuse approved logos, typography, colours and tone. Load domain guidance and packaging only when useful. Do not add a logo exploration or naming phase. If rules conflict, surface the conflict; if the user requests substantial creative departure, infer a campaign or identity change and record that scope explicitly.

Produce actual requested assets, inspect legibility and brand fidelity on their intended surfaces, and deliver sources/exports, application rules and QC. Missing brand assets or specifications should be named; a provisional concept must not be described as approved or production ready. Keep application outputs separate from master identity files.
