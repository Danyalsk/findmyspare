# Specialist contract

Return a concise, brief-specific synthesis, not a generic industry essay:

```yaml
module: domain-or-overlay
role: decision-this-module-informs
priorities: []
consequential_gaps: []
visual_possibilities: [{direction: string, rationale: string, tradeoff: string}]
cliches_and_failures: []
application_constraints: []
evaluation_criteria: []
assumptions: []
conflicts: []
evidence: []
```

The orchestrator merges overlapping findings into the compact brief, resolves conflicts and asks only consequential unanswered questions. Guidance below is a set of decision prompts, not a universal category style. Distinguish observed facts from hypotheses and source-derived principles from interpretation.
