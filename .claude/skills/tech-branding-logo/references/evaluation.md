# Evaluation protocol

Use the same brief, supplied references and image model/settings where feasible for baseline and upgraded runs. Start with an actual disappointing output and its original brief when available; without that pair, causation and improvement remain unproven. Keep output evaluation separate from automated routing/state checks.

| Scenario | Expected behaviour |
| --- | --- |
| New technology tool needs name and app identity | Technology + naming + identity; retain app and 16px checks when requested. |
| Named neighbourhood bakery needs storefront and menu | Food + name-to-brand; evaluate signage/menu, allow lettering; no compulsory favicon. |
| Property launch needs developer/project hierarchy | Real estate; clarify identity versus temporary launch only if ambiguous; preserve verified property facts. |
| Apparel brand needs permanent garment mark | Fashion + identity; evaluate label/print/embroidery, not just screen appearance. |
| Premium bakery supplies hotels, needs sales kit | Food/hospitality + B2B; packaging only if requested; combine buyer proof with category appeal. |
| Monochrome tee brand wants loud nostalgic summer campaign for students | Fashion + campaign; retain fixed cues, separate seasonal overrides, key visual and social assets. Do not ask again for audience/product/channel if given. |
| Existing identity needs a presentation | Application; reuse rules, no renaming or logo redesign. |
| Resume legacy state halfway through refinement | Infer identity scope, preserve mode/stage/unknown fields; no repeated intake. |

Score audience relevance, distinctiveness, coherence, legibility, practical usability and instruction adherence with concrete evidence. Record selected modules and why, question count (including redundant questions), actual context/token use when observable, model/settings, asset paths, unresolved constraints and judge rationale. Do not estimate token savings as measurements.

Acceptance: correct scope/useful modules, no fabricated product facts, no unapproved mutation of master identity, requested deliverables present or explicitly blocked, no repeated answered intake, and no QC blocker hidden by average scores. Use matched baseline/revised outputs to support any claim of improvement. Current release: protocol supplied; comparative visual evaluation pending original failed brief/output and controlled runs.
