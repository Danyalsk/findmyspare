# Logo workflow

Choose form from the brief: wordmark, lettering, monogram, emblem, illustration or symbol. For symbol exploration use concrete nouns and combinations (overlap, negative space, rhythm or modularity); full exploratory identity work can use 50 rough concepts. For type-led or narrowly scoped work, document a suitable exploration breadth instead of inventing 50 irrelevant symbols.

Refine recognition and black/white form first, then optical balance, spacing, line weight, type and colour. Produce only useful lockups and extensions. Judge originality against category context; do not use a badge or geometric mark by default.

Select functional tests from actual deliverables: favicon at 16×16 for a favicon, distance legibility for signage, stitch/print constraints for apparel, packaging hierarchy for packs. Check monochrome, contrast, smallest intended use and realistic backgrounds. Record untested surfaces as untested, not passing.

Prefer clean paths, explicit viewBox, editable sources, no accidental raster dependency and sensible filenames. Provide clear space, minimum size, misuse examples and exports. Verify fonts/licensing availability when distributing typography assets. A mockup is not production artwork.
