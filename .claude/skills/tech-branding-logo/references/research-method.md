# Specialist research backlog and capture

Status: initial modules are original working guidance. No book corpus has been supplied or verified for this expansion. The legacy *Logos That Last* attribution is indirect. Do not manufacture quotations, editions, page references or research completion.

Research food/FMCG purchase behaviour and packaging hierarchy; fashion brand codes, subcultures and editorial campaigns; real-estate place positioning and wayfinding; B2B buying groups and evidence; shared typography, composition, imagery and cultural context. Select sources for decisions they improve, not broad summaries. Verify bibliographic details against primary publisher/author sources and read accessible source material before extracting principles.

Capture each useful finding:

```yaml
source: {title: string, author: string, edition: string, chapter_or_page: string, access: full_text|excerpt|bibliographic_only}
principle_in_own_words: string
applies_when: []
does_not_apply_when: []
question_answered: string
design_decision: string
contrasting_examples: []
quality_check: string
source_derived_guidance: string
our_interpretation: string
limitations: []
```

Bibliographic metadata alone cannot support a chapter-level principle. Contemporary examples can test transfer but do not prove causation or market performance. Integrate only brief-relevant decisions into compact modules and preserve provenance here or in a linked evidence record. Do not turn observations into blanket category colour/style rules.
